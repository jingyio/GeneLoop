# 原始选定帧复核协议 V2

任务执行前冻结本协议与任务的 `qa.review_seconds`。基线与候选使用相同任务要求；不增加居中、装饰、风格等隐含标准。保留既有 V1 与 Flash 评审，不回刷旧判定。

1. `prepare_selected_review.py` 随机编码成片，输出原尺寸帧、实际帧号/时点、题面和独立媒体检查。审阅包不展示臂与成本，映射表单独存放。审阅前不读取该组成本；审阅者知道研究背景，仍存在偏倚。
2. 必须检查 `task_requirements`（明确要求的内容、标题、数据与布局）、`text_and_geometry`（字形完整、位置与允许区域）、`sampled_timing`（所看时点的镜头/覆盖状态）。按实际像素和显式任务要求逐项写观察，返回 passed/failed/unknown；无法判定不能写通过。
3. 使用原视频坐标，矩形左上角坐标不表示屏幕象限。时间窗口开始包含、结束不包含；用实际帧号/fps判断。源素材固有文字不算新覆盖层。
4. 采用共享 `geneloop.rsi/v1` 的 `quality_evaluation`，绑定任务、最终视频、评价协议摘要以及所看帧路径/SHA。宿主重新验证这些文件；缺失、变更或未知关键项暂停发布。技术/源帧/当前源码/音频检查失败不能由视觉判定覆盖。
5. 结论只覆盖选定原始帧与明确独立检查，不证明全片、未见过渡或完整音频质量，不称人工盲评。Codex 宿主审阅/开发成本未知；DeepSeek 的正常、失败、修复、学习与反思成本全部沿用累计账本。
6. 本轮仍使用冻结的至少20%前向模型费用下降、无新增所测质量失败及真实程序采用门槛。冷研究成本和未来摊销另报。候选不能修改本次评测器、协议或原始账本。
