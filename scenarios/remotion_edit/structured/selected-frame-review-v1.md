# 原始选定帧复核协议 V1

在新任务执行前固定本协议。由 Codex 查看实际像素并记录事实；这是 AI 抽帧复核，不能称为人工全片盲评。记录包不展示臂名或费用；同一编码聊天的审阅者知道研究背景，仍有偏倚限制。审阅前不读取该组的费用汇总。

- 仅复核当前最终视频，绑定任务摘要、视频 SHA256 和本协议摘要。记录所看原始帧的 SHA256、实际帧号/时点及具体观察。
- 检查任务明确要求的标题、文字位置、数据值、可见几何、字形完整性及提供时点的覆盖层状态。不自行增加居中、装饰、风格等要求。
- 使用原视频坐标。矩形左上角坐标不表示屏幕象限。时间窗口为开始包含、结束不包含；以实际帧号/fps确定时点。
- 源素材已有的字幕/片头不是新增覆盖层。源身份/时间只采用独立源帧检查的有限事实，必要时对照其实际源图；不从文件名猜场景。
- 技术、源帧、当前源码或音频窗口检查失败直接拒绝，像素复核不能将其改为通过。音频窗口通过也不能证明完整音频质量。
- 缺少关键状态、字形无法辨读或判断依据不足时记未验证，不能把推测写成通过。通过只覆盖所看帧与明确独立检查，不证明未见过渡或全片质量。
- 记录 accepted、observed_failures、visible_checks、limitations、reviewer=codex_actual_selected_frames、task_sha256、video_sha256、protocol_sha256 与逐帧证据。有效负面结果不重试到通过；旧 Flash 判定、费用和拒绝均保留。
- Codex 宿主的审阅用量/费用无法从 DeepSeek 账本核算，单独记未知，不能称为零。主实验继续完整统计 DeepSeek 正常、失败、修复、学习、反思和此前审阅请求；冻结质量要求与20%费用门槛不变。

缺少复核记录时外环暂停发布；补齐后从同一冻结计划续接，不重跑已有付费任务。后继任务也使用同一协议，新的程序候选仍须下一轮独立验证。
