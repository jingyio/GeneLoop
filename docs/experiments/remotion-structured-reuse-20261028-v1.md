## 假设与判据

假设：模型已选择具体素材后，固定素材句柄到读取同版本媒体属性的边可以从不同正常任务学习、在独立任务认证，并由现有TS在线Runtime安全替代完整模型请求。模型继续选择镜头、编写代码、判断交付。

这是很窄的机制实验，不代表完整剪辑流程复用。`pin_asset→probe_media`若不能认证、后继版本不匹配、没有完整请求verified skip，或同质量门槛下费用不降，则不支持该假设。即使成功，也必须对照直接融合操作的普通工具，不能只比较一个刻意拆细的接口。

## 四臂与冻结题目

三条不同单素材正常剪辑题用于2训练+1认证。它们只是不同技术剪辑决定，不是独立真实客户；先用单素材隔离最小参数边，不能把一个任务拆成多个“独立任务”。后续留出题包含多素材以检验迁移。实现时复用了已有witnessed-edge编译器，允许经过安全校验的多个见证；严格sequence路径的exactly-one限制不是整个系统的能力边界。

五条留出题在训练前冻结，每题四臂：

| 臂 | 接口与模式 | 可以说明什么 |

## 实现边界

复用原DSH循环、累计预算代理、Python `extract_dsh_trace/infer_dsh_provenance/mine_witnessed_parameter_edges/compile_witnessed_edge_motif/certify_witnessed_edge_motif/export_manifest`和现有在线Runtime。新增`plugin.ts`只接共享`installOnlineMotif`。不改上游Harness，不手写固定剪辑DAG冒充挖掘结果。

只认证只读素材句柄边。源码写入、渲染和笔记不被标成只读，也不计自动接管。渲染有当前源码摘要守卫，写入仅本任务生成目录；素材/依赖只读、容器禁网无凭证。像素预览通过真实MCP图片附件返回；[DeepSeek当前Vision说明](https://api-docs.deepseek.com/guides/vision/)支持Flash图片输入，但实际DSH链路仍须真实验证。

闭合`source_dereference`沿用现有无需语义再选择的窄路径。场景薄插件只接受这种认证库；若意外要求语义匹配，回退原模型，不使用固定相似度或模拟embedding冒充验收。单个候选本身不构成授权。

## start / defer / skip

- **start**：实际MCP schema、只读素材、路径/句柄/源码版本失效、真实无模型渲染及图片附件检查通过；账本旧前缀摘要冻结后，开始真实训练。
- **defer execute**：独立认证未通过、模式/代码/提示/工具schema摘要不一致、任务版本缺失或守卫失败；保持原模型。不能为了出正结果放宽认证。
- **skip扩大主张**：无完整verified skip、只减少token但实际总成本不降、质量门槛不满足，或与简单融合工具相当；照实报告限制，不把局部机制写成通用优势。

## 成本、质量与复现

所有臂`deepseek-flash`、reasoning off、输出6000；不限费用/请求，累计旧失败和新训练/认证/恢复，单任务900秒通知检查点。相同任务的顺序轮换，记录缓存命中/未命中及真实输入输出；5组只作局部观测，不声称稳定统计优势。工具集合差异和缓存影响明示。

独立验收至少检查尺寸/fps/帧数/全解码、指定时间点的源内容、首帧、字幕/布局和选定音频窗口。技术阈值、抽帧时点和原题同时冻结；本Agent审阅不是人工盲评。未评审质量仍为未知。费用比较同时报告成功率、媒体通过、已发现重大语义错误和失败；CPU/维护/人工仍需单列，代理估费不是实付账单。

## 真实结果与限制

3条普通真实任务共29次模型推理，代理估费USD0.01622325；11/10/8次分别对应缩放、色调转换、镜像对照，3份视频媒体检查通过。另16次Files API POST200传输图片，单列HTTP，不冒充模型请求或抹掉网络开销。实际账单未核对。
