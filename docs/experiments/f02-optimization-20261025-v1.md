## 已观察结果与失败

- 机会判断正确区分值得试验、待核验和跳过；在线启动绑定独立批准摘要、父版本、修改类型、训练/留出输入和质量标准。
- 配对评估检查完整两臂、费用/请求、质量、版本加载和实际采用。发布必须同时满足独立效果审核及原有认证/原子提交；缺少必要检查不发布。
- 真实重放最终仍为 `defer`：完整任务质量未评审，配置有变化，整次请求可替代性未证实。因此没有用局部计数正确推断可跳过模型。
- 一份冻结 Provider 投影保留了早期 unknown，原累计账本后来已有终态。重放导出器最初直接求和遇 `null` 失败；保留此失败及旧投影，按原始 request_id/model 与账本绑定生成新投影，未知由1变0。未覆盖旧数据、未假定零费用。新旧投影均因上述其他证据缺口保持待核验。
- F02 定向：**59 Python、43 Node 通过**。最初两项原生 HTTP 诊断因沙箱禁 localhost 得到 EPERM；允许本地监听后通过，未删检查。评测器字节摘要也被冻结，改变后拒绝评估/发布。
- 首轮全量Python1577通过/235跳过、Node1419通过/15跳过。冻结评测器代码版本后最终重跑：**Python1578通过/235跳过；Node1418通过/15跳过/1失败**。唯一失败仍是原基线已复现的超大上传 typed-413 ECONNRESET；未改网关，保留一过一败，不能挑选较早的通过声称最终全绿。smoke、motif:check 通过。
