## 假设与验收

原视频参数边只覆盖素材探测；反复编写 TSX、诊断和修复未被程序复用覆盖。假设参数化生成程序在新素材起点、时间轴、字幕和布局参数下减少模型输出与修复成本。不能把所有语义错误归因于复用形式，也不能承诺大幅提升。

首个效果目标为同等选定质量门槛下，实际模型费用至少下降20%；请求数、缓存/未缓存输入、输出、失败/恢复、端到端时间和学习成本分别报告。整体质量仍需真实像素审阅，选定源帧/音频窗口不能冒充人工盲评。全部失败进入统计，未知费用为null。

普通融合基线和程序复用臂保留相同的八个原生编辑工具及顺序，均可直接 `render_source(text)`，避免将源码写入/渲染合并的收益归因于程序学习。程序臂另加载冻结的学习库，模型显式选择程序并绑定当前参数；渲染仍实际执行，写权限与普通生成源码相同。目录形式增加两个目录/程序执行工具；类型化全库增加四个学出程序工具，检索选中单项时只增加一个，并不重复注册目录API。实际请求的工具集合分别为8/10/12/9项，工具接口差异本身是被测变量。

训练使用正常模型调用中新写的成功源码与匹配渲染收据，包括程序臂回退时的新源码；程序重放本身不能自证。候选先复现来源，再验证改变后的输入。新评测任务在运行前固定，评测后才允许进入下一代训练；训练、调优验证与最终评测分别记录。
